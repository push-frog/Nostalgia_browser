## ✨ Возможности

### 🎯 Основные (MVP)
- **Многооконный интерфейс** с вкладками в классическом стиле
- **Адресная строка** с автодополнением и поиском
- **6 поисковых систем**: Google, Yandex, Bing, DuckDuckGo, Mail.ru, Rambler
- **Поиск на странице** (Ctrl+F)
- **Менеджер загрузок** (Ctrl+J)
- **Контекстное меню** (копирование, открытие в новой вкладке, просмотр кода)
- **Масштабирование** (Ctrl + / - / 0, кнопки A- A+)
- **История просмотров** с датами
- **Избранное (закладки)**

### 🔒 Безопасность
- **Фильтрация сайтов**: чёрный и белый списки
- **Блокировка всплывающих окон**
- **Защита от небезопасных протоколов** (только http/https)
- **Режим инкогнито** (Ctrl+Shift+N) — без сохранения истории, cookie и кэша
- **Менеджер паролей** с базовой обфускацией (локальное хранение)
- **Управление cookie** — просмотр и удаление

### 🎨 Внешний вид
- **5 тем оформления**:
  - Классическая (вдохновлена настольными приложениями конца 90-х)
  - Морская (Teal)
  - Шоколадная
  - Лиловая
  - Тёмная (ночная)
- **Анимированный глобус** при загрузке (GIF)
- **Индикатор загрузки** на каждой вкладке
- **Статус-бар** с прогрессом и индикатором безопасности

### 🛠 Дополнительно
- **Очистка данных браузера** (Ctrl+Shift+Del)
- **Настройка домашней страницы**
- **Просмотр исходного кода** страниц
- **Полноэкранный режим** (F11)
- **Сохранение всех настроек** между сессиями

## 🚀 Установка и запуск

### Требования
- **Python 3.11** или **3.12** (⚠️ Python 3.13+ пока не поддерживается PyQt6 на всех платформах)
- Windows 10/11 (основная платформа, Linux/macOS — экспериментально)

### Быстрый старт

```bash
# Клонируем репозиторий
git clone https://github.com/yourusername/nostalgia-browser.git
cd nostalgia-browser

# Создаём виртуальное окружение
python -m venv venv

# Активируем (Windows)
venv\Scripts\activate
# Или на Linux/macOS:
# source venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt

# Запускаем
python browser.py
