## ✨ Возможности

### 🎯 Основные (MVP)
- **Многооконный интерфейс** с вкладками в классическом стиле (до 50 вкладок)
- **Умная адресная строка** с автодополнением, валидацией URL и поиском
- **6 поисковых систем**: Google, Yandex, Bing, DuckDuckGo, Mail.ru, Rambler
- **Поиск на странице** (Ctrl+F) с подсветкой результатов
- **Менеджер загрузок** (Ctrl+J) с прогресс-баром и проверкой безопасности файлов
- **Контекстное меню** (копирование, открытие в новой вкладке, просмотр кода)
- **Масштабирование страницы** (Ctrl+/Ctrl-/Ctrl+0, кнопки A-/A+)
- **История просмотров** с датами и дедупликацией
- **Избранное (закладки)** с импортом/экспортом HTML

### 🔒 Безопасность (НОВИНКИ v0.8.6)

#### Шифрование и защита данных
- **Мастер-пароль** (PBKDF2, 100 000 итераций) — обязателен при первом запуске
- **AES-128 шифрование** всех сохранённых паролей
- **Автоматическая блокировка** менеджера паролей через 5 минут неактивности
- **Защита от брутфорса** — 5 попыток, затем блокировка на 15 минут
- **Безопасное хранение ключей** в защищённой директории (%APPDATA%/NostalgiaBrowser/secure)

#### Сетевые защиты
- **Защита от DNS rebinding атак** — блокирует подмену IP в процессе сессии
- **Поддержка локальных сетей** (192.168.x.x, 10.x.x.x, 172.16.x.x) — автоматическое переключение на HTTP
- **Блокировка опасных протоколов** (javascript:, data:, vbscript:, file:)
- **Санитизация URL** — удаление чувствительных параметров из истории
- **Rate limiting навигации** — защита от DoS атак (10 запросов/сек)

#### Конфиденциальность
- **Режим инкогнито** (Ctrl+Shift+N) — полная изоляция: без истории, cookie и кэша
- **Защита от fingerprinting** — добавление шума в Canvas API
- **Автоочистка буфера обмена** через 30 секунд
- **SafeLogger** — санитизация логов, защита от инъекций
- **Очистка данных браузера** (Ctrl+Shift+Del):
  - История просмотров
  - Cookie и данные сайтов
  - Кэш браузера
  - Сохранённые пароли
  - Закладки

#### Защита пользователя
- **Фильтрация сайтов** — чёрный и белый списки с проверкой целостности
- **Блокировка опасных загрузок** — проверка MIME-типов и расширений
- **Защита от path traversal** — валидация всех путей к файлам
- **Анти-XSS** — удаление скриптов и опасных атрибутов из HTML
- **Мониторинг редиректов** — ограничение цепочки (максимум 10)
- **Ограничение размера страницы** — до 50 МБ

### 🎨 Внешний вид
- **5 тем оформления** в стиле Windows 98:
  - Классическая (Windows 98)
  - Морская (Teal)
  - Шоколадная
  - Лиловая
  - Тёмная (Ночная)
- **Анимированный глобус** при загрузке (поддержка GIF)
- **Цветной индикатор загрузки** на каждой вкладке (оранжевый → синий → зелёный)
- **Статус-бар** с прогрессом и индикатором безопасности:
  - 🏠 Локальная сеть — синий
  - 🔒 HTTPS — зелёный
  - ⚠ HTTP — оранжевый
- **Адаптивная палитра** под выбранную тему

### 🛠 Дополнительно
- **Просмотр исходного кода** страниц
- **Полноэкранный режим** (F11)
- **Сохранение всех настроек** между сессиями (JSON)

## 🚀 Установка и запуск

### Требования
- **Python 3.11** или **3.12** (⚠️ Python 3.13+ пока не поддерживается PyQt6 на всех платформах)
- **Windows 10/11** (основная платформа, Linux/macOS — экспериментально)
- **Минимум 4 ГБ ОЗУ** (рекомендуется 8 ГБ для сложных сайтов)

### Быстрый старт

```bash
# Клонируем репозиторий
git clone https://github.com/yourusername/nostalgia-browser.git
cd nostalgia-browser

# Создаём виртуальное окружение
python -m venv venv

# Активируем (Windows)
venv\Scripts\activate
# Или на Linux/macOS:
# source venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt

# Первый запуск — будет предложено создать мастер-пароль
python browser.py
